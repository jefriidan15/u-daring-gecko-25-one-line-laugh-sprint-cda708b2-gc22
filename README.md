## The line

> My printer only ever runs out of ink ten minutes before a deadline, which I have decided is not a coincidence but a small, petty form of time travel.

One sentence, 149 characters. A light, funny take on everyday
life: the printer, the deadline, and the suspicion that the
machine is doing it on purpose.

## Why this line works

- **Everyday life** — everyone has watched a printer die at the
  worst possible moment; the setup needs no explaining.
- **Laugh** — the twist reframes a boring malfunction as a
  deliberate act. The payoff lands on the last two words.
- **Fresh** — "a small, petty form of time travel" is a turn
  coined for this line, not a recycled punchline, and the printer
  never gets to explain itself.
- **Tight** — one sentence, no spare words, reads well aloud.

## How to run

Requires Python 3.13 (standard library only, no dependencies).

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` — UTF-8, one sentence,
149 characters, no trailing newline. Set `OUTPUT_DIR` to write
elsewhere:

```sh
OUTPUT_DIR=/tmp/out python3 main.py
```
